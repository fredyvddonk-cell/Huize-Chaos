# Huize Chaos

Gezinsplanner, recepten, voorraad en boodschappen.

Versie 1.3.14 laat het werkrooster per periode van vier weken invullen. Er kan tussen de vier weken en verschillende periodes worden gewisseld zonder tussentijds op te slaan. Alleen het huidige en volgende jaar zijn beschikbaar. Alle invoer wordt samen opgeslagen met Rooster opslaan.

Zie `FIREBASE-INSTELLEN.md` voor de eenmalige Firebase-instelling en het toevoegen van gezinsleden zonder e-mailadressen te delen.
