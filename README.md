# Huize Chaos

Gezinsplanner, recepten, voorraad en boodschappen.

Versie 1.3.10 maakt de onderdelen binnen een huishoudblok afzonderlijk afvinkbaar. De voortgang wordt gedeeld, zodat alle gezinsleden zien wat al klaar is en wat nog moet gebeuren. Het hele blok kan nog steeds in één keer worden afgerond.

Zie `FIREBASE-INSTELLEN.md` voor de eenmalige Firebase-instelling en het toevoegen van gezinsleden zonder e-mailadressen te delen.
