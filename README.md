# Huize Chaos V1.4.85
## Wijzigingen V1.4.85
- Recept kan nu rechtstreeks uit 1 of 2 foto's/screenshots worden toegevoegd.
- Picnic-import gebruikt standaard 4 personen.
- Herkende hoeveelheden worden bij ingrediënten gezet en uit de bereidingsstappen verwijderd.
- Eerste screenshot wordt automatisch als receptfoto gebruikt; deze is daarna vervangbaar.
- Foto toevoegen bij een nieuw recept weer betrouwbaar gemaakt.
- Foto vervangen bij bestaande recepten weer betrouwbaar gemaakt.
- Fotokiezer werkt via een duidelijke knop op mobiel en desktop.
- Receptfoto blijft automatisch verkleind voor snelle opslag en synchronisatie.
