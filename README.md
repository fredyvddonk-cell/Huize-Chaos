# Huize Chaos

Gezinsplanner, recepten, voorraad en boodschappen.

Versie 1.3.15 voegt bij afspraken het veld 'Voor wie?' toe, met ondersteuning voor meerdere personen. Conflicten worden gecontroleerd voor de betrokken personen. Bij een ziekenhuisafspraak kan direct een gekoppelde urgente taak worden gemaakt om school te informeren.

Zie `FIREBASE-INSTELLEN.md` voor de eenmalige Firebase-instelling en het toevoegen van gezinsleden zonder e-mailadressen te delen.
