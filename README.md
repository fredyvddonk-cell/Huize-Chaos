# Huize Chaos

Gezinsplanner, recepten, voorraad en boodschappen.

Versie 1.3.29 voegt in Voorraad & Boodschappen bij Voorraad en Beheer een zoekveld toe. Hiermee kan direct op productnaam worden gezocht. Tijdens het zoeken in Beheer opent het onderdeel Producten automatisch.

Zie `FIREBASE-INSTELLEN.md` voor de eenmalige Firebase-instelling en het toevoegen van gezinsleden zonder e-mailadressen te delen.
