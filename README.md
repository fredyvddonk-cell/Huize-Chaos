# Huize Chaos

Gezinsplanner, recepten, voorraad en boodschappen.

Versie 1.3.3 voegt optionele deadlines en urgente taken toe. De taak om de oude auto leeg te maken staat klaar met deadline 20 augustus 2026. Taken blijven zichtbaar totdat ze zijn afgevinkt en doorschuiven voorbij een deadline wordt tegengehouden. Deze plannergegevens blijven voorlopig lokaal op het apparaat. De gezamenlijke boodschappenlijst gebruikt Firebase.

Zie `FIREBASE-INSTELLEN.md` voor de eenmalige Firebase-instelling en het toevoegen van gezinsleden zonder e-mailadressen te delen.
