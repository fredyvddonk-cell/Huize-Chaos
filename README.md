# Huize Chaos

Gezinsplanner, recepten, voorraad en boodschappen.

Versie 1.3.36 versterkt de synchronisatie van de gezamenlijke boodschappenlijst. Naast de liveverbinding haalt de app de actuele boodschappen nu rechtstreeks van de server op bij openen, bij terugkeren naar de app en iedere 15 seconden zolang de app zichtbaar is. Hierdoor worden boodschappen die gezinsleden toevoegen ook verwerkt wanneer de liveverbinding op het toestel geen nieuwe melding doorgeeft.

Zie `FIREBASE-INSTELLEN.md` voor de eenmalige Firebase-instelling en het toevoegen van gezinsleden zonder e-mailadressen te delen.
