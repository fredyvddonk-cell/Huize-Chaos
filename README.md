Versie 1.3.58 synchroniseert Inzicht tussen apparaten via Firebase. Bonnen, productregels, maand- en weekbudgetten en aangeleerde productcategorieën worden gedeeld. Bestaande lokale Inzicht-data wordt veilig gemigreerd: als de cloud nog leeg is, kan alleen een apparaat met bestaande gegevens de cloud vullen, zodat een lege laptop de bonnen op de telefoon niet kan overschrijven. Wijzigen en verwijderen van bonnen wordt daarna live op andere apparaten doorgevoerd. V1.3.57 bonparserverbeteringen voor Albert Heijn en Picnic blijven behouden.
