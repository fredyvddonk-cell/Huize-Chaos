# Huize Chaos

Gezinsplanner, recepten, voorraad en boodschappen.

Versie 1.3.0 voegt de eerste Gezinsplanner toe met taken en afspraken van vandaag. Deze plannergegevens blijven voorlopig lokaal op het apparaat. De gezamenlijke boodschappenlijst gebruikt Firebase.

Zie `FIREBASE-INSTELLEN.md` voor de eenmalige Firebase-instelling en het toevoegen van gezinsleden zonder e-mailadressen te delen.
