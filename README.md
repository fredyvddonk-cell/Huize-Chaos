# Huize Chaos

Gezinsplanner, recepten, voorraad en boodschappen.

Versie 1.3.41 voorkomt dat een geopend actiemenu bij de drie puntjes vanzelf verdwijnt. De periodieke servercontrole vergelijkt voortaan eerst de online boodschappen met de laatst ontvangen gegevens. Alleen bij een werkelijke wijziging wordt de lijst opnieuw opgebouwd. Het menu met Wijzigen en Verwijderen blijft daardoor open totdat de gebruiker een keuze maakt of buiten het menu tikt.

Zie `FIREBASE-INSTELLEN.md` voor de eenmalige Firebase-instelling en het toevoegen van gezinsleden zonder e-mailadressen te delen.
