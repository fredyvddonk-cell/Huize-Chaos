# Huize Chaos

Gezinsplanner, recepten, voorraad en boodschappen.

Versie 1.3.13 voegt onder Taken op de pagina Vandaag een duidelijke koppeling naar Huishouden toe. Gezinsleden kunnen daardoor direct naar de huishoudblokken zonder zelf het tabblad te hoeven zoeken.

Zie `FIREBASE-INSTELLEN.md` voor de eenmalige Firebase-instelling en het toevoegen van gezinsleden zonder e-mailadressen te delen.
