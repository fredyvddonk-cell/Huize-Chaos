# Huize Chaos

Gezinsplanner, recepten, voorraad en boodschappen.

Versie 1.3.9 maakt de huishoudmodule overzichtelijker. Wekelijkse taken staan in enkele uitklapbare blokken en er verschijnt maar één periodieke extra klus tegelijk. De volledige takenbibliotheek blijft ingeklapt beschikbaar. Bij 'Toegevoegd door' wordt alleen de voornaam getoond.

Zie `FIREBASE-INSTELLEN.md` voor de eenmalige Firebase-instelling en het toevoegen van gezinsleden zonder e-mailadressen te delen.
