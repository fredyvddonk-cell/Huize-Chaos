Versie 1.3.54 voegt gerichte ondersteuning toe voor Picnic-bonnen die vanuit Outlook als PDF zijn opgeslagen. Huize Chaos herkent Picnic, gebruikt de bezorgdatum uit de bon, leest productregels en actieprijzen uit de PDF-layout en gebruikt het echte totaalbedrag. De bestaande bonherkenning voor andere winkels blijft behouden.
