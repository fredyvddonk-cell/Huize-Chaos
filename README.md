Versie 1.3.52 lost de ontbrekende bonopties in Boodschappen → Inzicht op. Bij iedere aankoop staat nu zichtbaar een driepuntjesmenu met Bon wijzigen en Bon verwijderen. Tikken op de bon zelf opent nog steeds alleen Bon bekijken. Verwijderen vraagt om bevestiging en heeft geen invloed op voorraad of boodschappenlijst. De bestaande bon-uitlezing en overige functies zijn ongewijzigd.
