# Huize Chaos

Gezinsplanner, recepten, voorraad en boodschappen.

Versie 1.3.1 breidt de Gezinsplanner uit met datums, aankomende afspraken en terugkerende taken zonder vaste dag. De autoverzorging en de afspraak voor het ophalen van de auto zijn toegevoegd. Deze plannergegevens blijven voorlopig lokaal op het apparaat. De gezamenlijke boodschappenlijst gebruikt Firebase.

Zie `FIREBASE-INSTELLEN.md` voor de eenmalige Firebase-instelling en het toevoegen van gezinsleden zonder e-mailadressen te delen.
