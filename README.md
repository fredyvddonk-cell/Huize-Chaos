# Huize Chaos

Gezinsplanner, recepten, voorraad en boodschappen.

Versie 1.3.2 toont terugkerende taken pas vanaf de gekozen startdatum. Dagelijkse routines staan op een apart blad. Wekelijkse huishoudtaken zijn toegevoegd en er wordt maximaal één periodieke grote klus tegelijk getoond. Na afvinken verschijnt de volgende. Taken kunnen naar morgen worden doorgeschoven. Deze plannergegevens blijven voorlopig lokaal op het apparaat. De gezamenlijke boodschappenlijst gebruikt Firebase.

Zie `FIREBASE-INSTELLEN.md` voor de eenmalige Firebase-instelling en het toevoegen van gezinsleden zonder e-mailadressen te delen.
